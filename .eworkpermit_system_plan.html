System Overview

PHASE 1
วัตถุประสงค์: พัฒนาระบบ Digital Safety Management สำหรับบริษัท โดวะ เทอร์โมเทค ครอบคลุมการจัดการ E-Work Permit และการควบคุมผู้รับเหมา ทดแทนกระบวนการกระดาษ เพิ่มความรวดเร็ว ลด Human Error และสร้าง Audit Trail ที่ตรวจสอบได้

📝 Module 1: E-Work Permit

  • สร้าง Work ใหม่พร้อม Task ย่อยสำหรับการอนุมัติ
  • รองรับ Hot Work และ Cold/Non-Routine Work
  • Generate Link ส่งให้ผู้รับเหมากรอกข้อมูล
  • ระบบ Digital Signature ลงนามออนไลน์
  • Approval Flow 4 ขั้น พร้อม Email แจ้งเตือน
  • แนบ KYM Sheet, Daily Check Sheet
  • บันทึกปัญหาระหว่างปฏิบัติงาน
  • ปิดงาน (Job Closure) ออนไลน์

👷 Module 2: Contractor Control

  • ลงทะเบียนผู้รับเหมาพร้อม PDPA Consent
  • เก็บใบ Certificate และวันหมดอายุ
  • ติดตามสถานะการอบรม (Training Record)
  • แจ้งเตือนเมื่อบัตร/ใบเซอร์ใกล้หมดอายุ
  • พิมพ์บัตรประจำตัวผู้รับเหมาจากระบบ
  • ทะเบียนบริษัทผู้รับเหมา
  • ดู Timeline ประวัติการเข้า Work Permit
  • Export รายงานสรุป

▸ ขอบเขต Work Permit ที่รองรับ

🔥 Hot Work

  • เจียร/ตัด
  • เชื่อม/ดัด
  • ขุด/เจาะ
  • เผา
  • อื่นๆ ที่มีประกายไฟ/ความร้อน

❄️ Cold Work & Non-Routine

  • งานทั่วไปที่ไม่ใช่งานประจำ
  • งานติดตั้ง/รื้อถอนนั่งร้าน
  • งานในที่สูง (≥2 เมตร)
  • งานก่อสร้าง/เสาเข็ม/ปั้นจั่น
  • งานไฟฟ้า / งานสารเคมีอันตราย
  • งานยกของหนักด้วยเครื่องจักร

Feature Design รายละเอียด

ALL MODULES

1 Work Permit Management

📋 Work List & Dashboard

  • ตารางรายการ Work Permit ทั้งหมดพร้อม Filter (สถานะ, วันที่, ประเภทงาน, พื้นที่)
  • Badge แสดงจำนวน Permit ที่รอดำเนินการแต่ละสถานะ
  • ค้นหาด้วย Work ID, ชื่อบริษัท, พื้นที่
  • Export to Excel/PDF

➕ สร้าง Work Permit ใหม่

  • กรอก Header: บริษัท, พื้นที่, วันที่, จำนวนคน, ผู้คุมงาน, เจ้าของงาน
  • เลือกประเภทงาน (Hot/Cold/Non-Routine) และ Sub-type
  • เลือก PPE ที่ต้องใช้ (Checkbox รายการ)
  • แนบเอกสาร: ลงทะเบียน, KYM Sheet, รายชื่อ
  • ระบบ Auto-generate Permit ID (FR-HR-34-YYYYMMDD-XXX)

🔗 Contractor Link Generation

  • สร้าง Unique Token URL สำหรับผู้รับเหมากรอกข้อมูล
  • Link มีอายุ 48 ชั่วโมง (configurable)
  • ผู้รับเหมา fill form ไม่ต้องล็อกอิน
  • OTP SMS/Email ยืนยันตัวตนก่อนกรอก
  • ส่ง Link ผ่าน Email อัตโนมัติ

✍️ Digital Signature & Approval

  • Signature pad (draw on screen) หรือ Type + Timestamp
  • แสดง Audit Trail: ใครอนุมัติ เวลาเท่าไหร่
  • คืนกลับ (Return) พร้อมระบุเหตุผล
  • PDF Preview ก่อนลงนาม

🚧 Problem Tracking ระหว่างงาน

  • บันทึกปัญหา: วันที่, รายละเอียด, วิธีแก้ไข
  • ระบุผู้รับผิดชอบและวันที่เสร็จ
  • บันทึกผลการแก้ไขและผู้ตรวจสอบ

🔒 Job Closure

  • Checklist ปิดงาน: ทำความสะอาด, ตรวจสอบความปลอดภัย
  • ลงนาม 3 ฝ่าย: เจ้าของงาน, จป.Safety, ผจก.บุคคล
  • Generate PDF เอกสารสมบูรณ์
  • Archive ไปยัง Document Storage

2 Contractor Person Management

👤 ลงทะเบียนผู้รับเหมา (Individual)

  • ข้อมูลส่วนตัว: ชื่อ-นามสกุล, เลขบัตรประชาชน, วันเกิด, สัญชาติ
  • ข้อมูลติดต่อ: เบอร์โทร, Email
  • รูปถ่าย (อัพโหลด/ถ่ายจาก Webcam)
  • สังกัดบริษัทผู้รับเหมา
  • สถานะ: Active / Inactive / Blacklist
  • PDPA Consent (บันทึกวันที่ยินยอม)

📄 Certificate Management

  • Upload ใบเซอร์ (PDF/Image) พร้อม Metadata
  • ประเภทใบเซอร์: Safety Training, Hot Work, Confined Space, ฯลฯ
  • วันออก / วันหมดอายุ
  • แจ้งเตือน 30/15/7 วันก่อนหมดอายุ
  • สถานะ: Valid / Expiring Soon / Expired

📝 PDPA Document

  • แบบฟอร์ม PDPA Digital (Part 1 ความยินยอม, Part 2 ข้อมูลสุขภาพ)
  • บันทึก IP, Timestamp, Device
  • Download PDF สำหรับเก็บเอกสาร
  • ต่ออายุความยินยอมเมื่อครบกำหนด

🪪 Contractor ID Card

  • Template บัตรประจำตัว (หน้า-หลัง)
  • QR Code เชื่อมระบบ เพื่อสแกนตรวจสอบ
  • แสดงวันหมดอายุบัตร และ CER ที่มี
  • Print-ready PDF A5 หรือ Credit Card Size
  • บันทึกวันที่ออกบัตรและผู้ออกบัตร

📚 Training History

  • รายการอบรมทั้งหมดของแต่ละคน
  • คะแนนผ่าน/ไม่ผ่านการทดสอบ
  • Link ไปยัง Work Permit ที่เคยเข้าร่วม
  • Export รายงานประวัติส่วนตัว

🏢 Contractor Company Registry

  • ทะเบียนบริษัทผู้รับเหมา: ชื่อ, เลขทะเบียน, ผู้ติดต่อ
  • รายชื่อพนักงานในสังกัด
  • สัญญาว่าจ้าง วันเริ่ม-หมดสัญญา
  • Blacklist บริษัท / บุคคล

3 Administration & Reports

📊 Dashboard & Analytics

  • กราฟ Work Permit ตามสถานะ (Real-time)
  • จำนวน Permit แยกตามประเภทงาน/พื้นที่
  • Expiry Alert Widget (CER/บัตรผู้รับเหมา)
  • Permit ที่ค้างอยู่ในแต่ละขั้นอนุมัติ

🔐 User & Role Management

  • กำหนด Role: Admin, Safety Officer, Work Owner, Area Owner, HR Manager
  • Permission Matrix ต่อ Feature
  • SSO / Active Directory Integration (Optional)
  • Login Log / Activity Log

Email Notification System

AUTO
Email Engine: ระบบส่ง Email อัตโนมัติผ่าน SMTP (หรือ SendGrid/AWS SES) โดย Template เป็นภาษาไทย มี Link Deep-link กลับไปยัง Work Permit นั้นๆ และบันทึกสถานะการส่งไว้ใน notifications table

▸ Work Permit Events

TRIGGER: WP Created
📋 แจ้งสร้าง Work Permit ใหม่
ถึง: ผู้รับเหมา (Contractor Link), จป.Safety, เจ้าของงาน
TRIGGER: WP Submitted
📨 ผู้รับเหมาส่งเอกสารแล้ว
ถึง: เจ้าของงาน (พร้อม Link อนุมัติ)
TRIGGER: Step 1 Approved
✅ เจ้าของงานอนุมัติแล้ว
ถึง: เจ้าของพื้นที่ (พร้อม Link อนุมัติ)
TRIGGER: Step 2 Approved
✅ เจ้าของพื้นที่อนุมัติแล้ว
ถึง: จป./Safety Officer
TRIGGER: Step 3 Approved
✅ จป.Safety อนุมัติแล้ว
ถึง: ผจก.บุคคลและบริหาร
TRIGGER: FINAL Approved
🎉 Work Permit อนุมัติครบแล้ว
ถึง: ผู้รับเหมา, เจ้าของงาน, จป.Safety, รปภ.
TRIGGER: WP Returned
🔁 ส่งกลับแก้ไข
ถึง: ผู้รับเหมา (พร้อมเหตุผลและ Link แก้ไข)
TRIGGER: WP Closed
🔒 ปิดงานแล้ว
ถึง: ทุกฝ่าย พร้อม PDF Summary

▸ Scheduled Jobs (Cron)

⏰ Daily 08:00 — Expiry Check

  • ตรวจ Certificate ที่ expiry_date = วันนี้ + 30/15/7 วัน
  • ตรวจบัตรผู้รับเหมา card_expiry_date
  • Queue Email notification

⏰ Daily 07:00 — Permit Reminder

  • Permit ที่ยัง Pending เกิน 24 ชั่วโมง
  • ส่ง Reminder ถึง Approver ถัดไป
  • Escalate ถ้า Pending เกิน 48 ชั่วโมง

⏰ Weekly Monday — Summary Report

  • สรุป Permit ของสัปดาห์ที่ผ่านมา
  • จำนวน Open/Closed/Pending
  • ส่งให้ Safety Officer และผู้บริหาร

Role & Permission Matrix

ACCESS CONTROL

🔧 Admin

  • จัดการ User และ Role
  • Config Approval Flow
  • ตั้งค่าระบบทั้งหมด
  • ดูรายงานทุกอย่าง

🦺 Safety Officer (จป.)

  • สร้าง/ดู Work Permit ทั้งหมด
  • อนุมัติ Step 3
  • Generate Contractor Link
  • จัดการ Contractor ทั้งหมด
  • ดู Dashboard + Export

👔 Work Owner (เจ้าของงาน)

  • สร้าง Work Permit ของตนเอง
  • อนุมัติ Step 1
  • ดู Permit ของตนเอง
  • บันทึกปัญหาระหว่างงาน

🏭 Area Owner (เจ้าของพื้นที่)

  • อนุมัติ Step 2
  • ดู Permit ในพื้นที่รับผิดชอบ

👩‍💼 HR Manager (ผจก.บุคคล)

  • อนุมัติ Step 4 (Final)
  • ออกบัตรผู้รับเหมา
  • จัดการทะเบียนผู้รับเหมา
  • ดู PDPA Records

🔐 Guard (รปภ.)

  • สแกน QR บัตรผู้รับเหมา
  • ดูสถานะ Permit ปัจจุบัน
  • Check-in / Check-out

▸ Security Considerations

🔐 Data Security

  • เข้ารหัส AES-256 สำหรับ National ID และข้อมูล PDPA
  • HTTPS บังคับทุก Endpoint
  • JWT มีอายุสั้น + Refresh Token Rotation
  • Rate Limiting บน API

📜 Audit & Compliance

  • Audit Log ทุก Action (who, when, what, IP)
  • ไม่ลบข้อมูลจริง (Soft Delete)
  • PDPA Compliance: เก็บข้อมูลสุขภาพแยก
  • Document Retention Policy กำหนดได้
